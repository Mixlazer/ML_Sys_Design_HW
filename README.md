# Smart LLM Router

Лазарчик Михаил Павлович, ИТМО. Проект курса по дизайну ML-систем.

Маршрутизатор подбирает готовую языковую модель с учётом домена, языка и признаков сложности запроса. Задача — снизить полную стоимость обработки при сопоставимых качестве и задержке. В эксперименте будут сравниваться фиксированная модель, самый дешёвый допустимый вариант и автоматический выбор по профилям качества. Учитываются локальные вычисления, облачные платежи и расходы всех попыток.

## Воспроизведение

Запуск проверен на CPython 3.12 и 3.13. Для EDA достаточно CPU. Команды выполняются из корня репозитория.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[eda,dev]"
python scripts/fetch_data.py
python scripts/eda.py
python -m unittest discover -s tests -v
python -m ruff check .
python -m ruff format --check .
python -m pre_commit run --all-files
```

В Windows вместо `source` используется `.\.venv\Scripts\Activate.ps1`. При первой установке нужны доступ к пакетам и адресам из файла источников, словарь tiktoken и репозитории проверок pre-commit. Для повторного расчёта без сети храните `data/raw` и кеш tiktoken. Путь к словарю можно указать через `TIKTOKEN_CACHE_DIR` до первого запуска.

Скрипт загружает пять снимков заданий и список замен MGSM-Rev2. SHA-256 и размер сверяются перед записью и при чтении. EDA пишет результаты в `reports/` и выполняет только статические проверки заданий Python.

Материалы первого задания лежат в ветке [hw_1](https://github.com/Mixlazer/ML_Sys_Design_HW/tree/hw_1).
